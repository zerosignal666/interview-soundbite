# 整段选字幕与时间码换算

`scripts/clip_srt.py` 仅用Python标准库。输入一份标准SRT和一个UTF-8 JSON方案，保留源字幕文本，包括换行、重复和疑似错字。默认按UTF-8（允许BOM）读取字幕；其他编码可用 `--encoding gb18030` 等明确指定，解码错误不静默吞掉。

## 方案

以下小例子只说明字段，不是固定选段或栏目模板。`first` 和 `last` 是原SRT里的字幕序号，包含两端；每个选择区间会保留其间所有条目和段内空隙。数组顺序就是成片顺序，可与源时间先后不同。

```json
{
  "title": "采访选段示例",
  "theme": "依据本次用途确定内容重点",
  "target_seconds": 45,
  "segments": [
    {"label": "A 核心表达", "first": 21, "last": 28,
     "purpose": "选用与本次内容重点直接相关的表达",
     "join_note": "起点需保留必要语境；接点需回听"},
    {"label": "B 补充细节", "first": 4, "last": 10,
     "purpose": "用细节使上一段的表达更容易理解"},
    {"label": "C 收束片段", "first": 90, "last": 97,
     "purpose": "按本次作品需要安排结尾",
     "join_note": "出点需回听尾音与停顿"}
  ],
  "notes": ["部分转写措辞有疑点需回听", "本方案尚未试听原声"]
}
```

- `segments` 必填且非空；每项 `first`、`last` 必须是存在的整数序号，入点在出点之前。`label`、`purpose`、`join_note` 可省略。
- `title`、`theme`、`target_seconds`、`notes` 可省略。`target_seconds` 只用于报告实际与目标的差值，不会自动删词、变速或凑时长。
- 不重复选同一字幕，不选择相互重叠的源区间；需要重复引用或复杂音频叠化时另行建立明确的剪辑方案。
- 需要一条字幕内部的裁切时，先回听并记录真实音节边界，另行处理；此脚本不提供猜测性句内切词。

## 命令与输出

```text
python scripts/clip_srt.py --source interview.srt --plan selection.json --out cut-v1
```

输出4个文件：

1. `01_source_timecodes.srt`：选中字幕按源时间排列；用于源采访时间轴定位。
2. `02_edit_timecodes.srt`：按方案数组顺序从零拼接；保留每段内部原有间隙。
3. `03_edit_sheet.md`：每段源时间／成片时间、长度、完整原话及填写的剪口建议。模型需补充内容层面的复核结果。
4. `04_edit_map.json`：记录源路径、源文件SHA-256、实际时长、顺序、原字幕序号以及每条字幕的源／成片时间。毫秒整数为计算依据。

已有同名输出时默认报错。明确更新同一方案可加 `--overwrite`；需要对比方案则用不同输出目录。原SRT和方案文件不会被脚本改写，输出目录也不能覆盖它们。

## 校验边界

脚本检查源字幕可解析、序号唯一、时间有效且未倒退，选段存在且不重复／不重叠；输出后复读核对文本与时间码的换算。原定位字幕和成片字幕分别按自己的时间轴校验。

脚本不能确认说话人、语义是否被误剪、声画对应、音节切点、术语汉字和视频软件导入表现。总时长包括选中各整段内部的空隙；字幕持续时间之和不一定等于整个段落长度。若脚本发现重叠或时间轴重置，先检查是否为字幕问题或多个源片，不能为了让校验通过擅自改时间。
